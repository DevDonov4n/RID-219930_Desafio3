# 🗂️ Board de Tarefas — Desafio 3 | Escola DNC

Este projeto faz parte do **Desafio 3 da Escola DNC**, com o objetivo de consolidar conhecimentos em **HTML, CSS e JavaScript**, aplicando boas práticas de organização, responsividade e manipulação de estado no front-end.

O projeto consiste em um **Board de Tarefas interativo**, onde o usuário pode criar, concluir, etiquetar e gerenciar tarefas de forma simples e intuitiva.

---

## 🎯 Objetivo do Projeto

Desenvolver uma aplicação front-end que permita:

- Criar tarefas dinamicamente
- Marcar tarefas como concluídas
- Adicionar etiquetas às tarefas
- Contabilizar tarefas concluídas
- Remover tarefas finalizadas
- Garantir uma experiência totalmente responsiva (mobile e desktop)

---

## 🧩 Funcionalidades Implementadas

✔️ Adicionar novas tarefas  
✔️ Adicionar etiqueta abaixo do nome da tarefa  
✔️ Marcar tarefas como concluídas  
✔️ Animação ao concluir tarefas  
✔️ Contador de tarefas concluídas  
✔️ Remoção de todas as tarefas concluídas  
✔️ Persistência de dados com `localStorage`  
✔️ Layout responsivo para mobile e desktop  

---

## 🖥️ Layout Responsivo

- **Mobile-first**
- Centralização correta da aplicação em qualquer tamanho de tela
- Uso de `100svh` para evitar bugs de viewport no mobile
- Board com largura máxima controlada
- Lista de tarefas com rolagem interna

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estrutura semântica
- **CSS3** — Flexbox, pseudo-elementos, animações e responsividade
- **JavaScript (Vanilla)** — Manipulação do DOM, estados e eventos
- **LocalStorage** — Persistência das tarefas
